3 How It Works

Each letter becomes a number (A=0 … Z=25), the key is added or subtracted, and the result wraps around with mod 26.

Encrypt or decrypt something above to see each step.

4 Attack: Brute Force

There are only 26 possible keys, so an attacker can simply try them all and read which result makes sense.
